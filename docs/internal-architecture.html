未実装領域

「バグ」ではなく、現行設計が明示的に線を引いている範囲です。

Language surface

クロージャと高度な generics

無名関数は構文と AST まで実装済み。本体の型検査・捕捉・実行、明示型引数、generic struct / enum、制約付き型パラメータは未実装。

Ownership edge

aggregate borrow / shared ownership

borrow の値への格納、RC / GC、raw pointer、unsafe は持たない。公開 ABI に borrow も出せない。

Execution model

async と継続

async/await、generator、backtracking、language-level unwinding は非対応。tail-resumptive の境界を維持。

Compiler services

個別・増分コンパイル

型・ambient・borrow は whole-program 前提。モジュール単独型検査、incremental build、最適化 pipeline は未実装。

Developer experience

LSP と package manager

エディタ統合、外部パッケージ解決、配布レジストリはまだない。

Targets

native / Component

生成対象は Core Wasm。native、WIT、WASI、Component Model は言語契約の外で下流アダプタに委ねる。
